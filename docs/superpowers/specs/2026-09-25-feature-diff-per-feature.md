# Features: new feature step vs legacy, difference per feature

Same objects, same light-curve epoch: features from the new feature step against the vector the
legacy pipeline stored. Cohort A: 1,000 objects sampled at random from everything legacy
classified. Cohort B: 100 objects whose legacy top class is Transient.

**What drives the differences.** Every large value in the table comes from one of four input
differences between the two pipelines, named in the `driver` column. The `same inputs` columns
repeat p95 and p99 on the objects where that difference is absent: same detection set, WISE on
both sides or on neither, and an identical period (212 objects in A, 64 in B).

- **detections**: 307 of the 1,000 objects in A (3 of 100 in B) have a different detection set
  in the two databases, so everything averaged over detections moves. With the same set the
  statistics are identical: `Amplitude_1` p99 goes from 0.031 to 0.002, `Mean_1` p95 from
  0.0066 to 0.00006 mag.
- **WISE match**: our crossmatch finds a WISE source for 26 objects in A (6 in B) where legacy's
  vector has none, never the reverse. Where both have it the colours are identical: `r_W1` p95
  goes from 0.0056 to 0.000003.
- **period**: the two pipelines land on the same period peak for 75 % of the objects in A that
  have one; the rest is another optimum of the same near-degenerate periodogram (one-day alias
  or harmonic). Even on the same peak the value is identical for only a third of them, the rest
  differ below 1e-4, and the harmonic fit turns that into large phase differences over a
  multi-year baseline. With an identical period: `Multiband_period_12` p95 goes from 0.68 to
  0.000001 d, `Power_rate_2_12` from 0.22 to 0.019, `Harmonics_phase_2_1` from 5.7 to 0.47 rad.
- **fit**: SPM, fleet, microlensing, TDE and Gaussian-process fits are optimisers; their epochs
  and chi-squares keep a tail even with the same inputs (`SPM_t0_1` p95 304 to 231 d in A). On
  the transients of B, where these fits matter, the tail is smaller: `SPM_t0_1` median 0.07 d,
  p95 24 d, 6.6 d with the same inputs.

|ours − legacy| / |legacy|; then p95 and p99 on the same-inputs objects. Sorted by the Cohort A
median, largest first.
